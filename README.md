# Offline Task Manager

A React-based task management application that works completely offline, utilizing localStorage for data persistence. Built with React and Tailwind CSS, featuring a beautiful UI with dark/light mode support.

## Features

- ✅ Create, edit, and delete tasks
- ✅ Mark tasks as completed
- ✅ Categorize tasks (Work, Personal, Urgent)
- ✅ Filter tasks by category
- ✅ Dark/Light mode theme toggle
- ✅ Responsive design
- ✅ Offline-first with localStorage persistence

## Tech Stack

- React.js
- Tailwind CSS
- ShadcN UI Components
- localStorage for data persistence
- Wouter for routing

## Getting Started

1. Clone the repository:
```bash
git clone https://github.com/yourusername/offline-task-manager.git
```

2. Install dependencies:
```bash
cd offline-task-manager
npm install
```

3. Start the development server:
```bash
npm run dev
```

4. Open [http://localhost:5000](http://localhost:5000) in your browser.

## Build for Production

To create a production build:

```bash
npm run build
```
